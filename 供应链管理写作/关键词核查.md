# 全文关键词与术语核查表

| 处理处置节点 | 处理设施、处置设施、处理节点、设施端 | 接收、暂存并处理危化废弃物的节点 |

| 周期 | 时期、时段 | 指模型离散时间集合时使用 |
| 共载附加风险 | 混装风险、叠加风险 | 指兼容危化废弃物同弧共载产生的额外风险 |

| 改进式深度强化学习 | 生成式算法、构造式算法 | 描述本文方法；后两者仅用于对比其他方法 |
| 策略网络／价值网络 | Actor网络／Critic网络、中英文混用 | 首次可注明英文，后文使用中文名称 |

| 多头自注意力机制 | 多头注意力、自注意力机制混用 | 首次给出全称，后文可简称多头自注意力 |
| 查询矩阵／键矩阵／值矩阵 | Query／Key／Value反复中英文混用 | 首次可在括号中注明英文，后文统一使用中文名称 |
| 缩放点积注意力 | 配合度、注意力得分混用 | 指查询矩阵与键矩阵缩放点积并经Softmax得到权重的过程 |

| 残差连接 | Skip-Connection、中英文混用 | Transformer两个子层均使用残差连接 |

| 掩码平均池化 | 普通平均池化、mean pooling | 汇总token编码时排除行方向补零token |
| 线性输出头 | 池化后共享MLP | 当前full_transformer配置由池化结果直接连接四个策略头和一个价值头 |
| 复合动作 | 联合动作、组合操作 | 指“邻域算子—三个操作对象”动作 |
