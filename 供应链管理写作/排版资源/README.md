# 论文公式排版资源

Codex 的 Markdown 文件预览支持本地图片，但当前不解析 LaTeX 数学公式。因此论文使用 PNG 展示公式，并保留同名 SVG 矢量版和 `.tex` 源文件；公式含义及实验数值未改变。

- `目标函数`：当前实例固定参考尺度下的成本—风险加权目标。
- `弱覆盖率`：满足两个目标弱不等式的第二集合中点数，除以第二集合基数；相等点仍计入。
- `相对差异`：PPO 相对同偏好 MILP 的目标差异百分比。

PNG 使用白底、300 dpi、统一画布宽度，不依赖外部字体下载或联网公式服务。移动论文时请同时保留本目录，以保持 Markdown 相对图片链接有效。在编辑器中选中图片语法时可能暂时显示源码；将光标移到普通文字即可回到图片展示。

从项目根目录运行 `py -B render_manuscript_equations.py` 只重建本目录公式资源，不读取或重跑任何实验。完整论文表格仍是可编辑的标准 Markdown 表格，没有将数据表替换成图片。
