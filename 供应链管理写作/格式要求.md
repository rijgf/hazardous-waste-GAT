# 《工业工程与管理》论文格式要求

本文档依据同目录下的 `论文模板 (2).doc` 正文格式示例及 Word 内部格式参数整理。

> 所有论文内容均应基于论文模板副本进行写作和修改。

## 一、强制写作方式

> **正式写作必须先复制一份 `论文模板 (2).doc`，然后只在模板副本中替换占位内容和补充正文。不得新建空白 Word 文档后从头构建，也不得自行重新制作版式。**

具体要求：

1. 保留原始 `论文模板 (2).doc` 不动，复制并重命名一份作为论文工作文件。
2. 在副本中直接替换中文题名、作者、单位、摘要、关键词、英文信息、正文、表格和参考文献内容。
3. 新增同类内容时，应复制模板中对应的示例段落、标题、表格或参考文献条目后再改文字，优先继承模板既有样式，不要凭目测重新设置。
4. 保留模板的 A4 页面设置、页边距、脚注区、页码、标题层级和表题位置。
5. 完稿前删除模板中的红色格式说明文本框、灰底提示和占位方框，但不得误删正文格式、脚注或页码。
6. 若本文档中的文字说明与模板的实际样式发生冲突，以模板副本中的既有版式和样式为准。

## 二、页面设置

- 纸张：A4，纵向，单栏。
- 模板结构：1 个节；不区分奇偶页，也不设置首页不同。
- 页面尺寸：宽 21.0 cm，高 29.7 cm。
- 上、下页边距：各 2.54 cm。
- 左、右页边距：各约 3.17 cm。
- 页眉距页面顶端：约 0.50 cm；模板页眉为空，不要自行增加页眉内容。
- 页脚距页面底端：约 0.40 cm。
- 页码：阿拉伯数字，位于页脚右侧，连续编号；Times New Roman 9 pt（小五号）。

## 四、首页信息与中英文摘要

| 内容 | 字体与字号 | 对齐及其他要求 |
| --- | --- | --- |
| 中文题名 | 小二号宋体（18 pt） | 居中；段前、段后各约 6 pt |
| 中文作者 | 五号宋体（10.5 pt） | 居中；作者单位用上标序号对应，通信作者加 `*` |
| 中文作者单位 | 小五号宋体（9 pt） | 居中；按“单位，省市 邮编”书写 |
| “摘要：” | 五号黑体（10.5 pt），加粗 | 与摘要正文同段排版 |
| 中文摘要正文 | 五号楷体（10.5 pt） | 两端对齐，1.5 倍行距 |
| “关键词：” | 五号黑体（10.5 pt），加粗 | 与关键词同段排版 |
| 中文关键词 | 五号楷体（10.5 pt） | 关键词之间使用分号 |
| 中图分类号、文献标志码 | 五号宋体（10.5 pt） | 同一行排版，按模板位置填写 |
| 英文题名 | 小二号 Times New Roman（18 pt） | 居中；含义与中文题名一致 |
| 英文作者 | 五号 Times New Roman（10.5 pt） | 居中；姓大写，单位上标序号与中文对应 |
| 英文作者单位 | 小五号 Times New Roman（9 pt） | 居中 |
| “Abstract:” | 五号 Times New Roman（10.5 pt），加粗 | 与英文摘要正文同段排版 |
| 英文摘要正文 | 五号 Times New Roman（10.5 pt） | 两端对齐，1.5 倍行距 |
| “Key words:” | 五号 Times New Roman（10.5 pt），加粗 | 与英文关键词同段排版 |
| 英文关键词 | 五号 Times New Roman（10.5 pt） | 与中文关键词对应；除专有名词外使用小写 |

摘要内容要求：

- 中文摘要宜为 200—300 字，以研究目的、方法、结果和结论为基本结构，其中结果和结论最重要。
- 使用第三人称，不以“本文”“作者”等作主语；摘要应能独立成文，不作评价或补充解释。
- 摘要中原则上不使用图、表、公式和非公知符号，不引用文献；缩略语首次出现时应说明。
- 英文题名应与中文题名含义一致；模板要求第一个实词的首字母大写。
- 英文摘要一般不超过 250 个实词，与中文摘要对应。叙述研究工作宜用过去时，叙述结论宜用现在时；尽量使用主动语态，避免冗长修饰和以辅助从句开头。

## 五、正文和标题层级

- 正文中文使用五号宋体（10.5 pt），英文、数字和拉丁字符使用 Times New Roman。
- 正文两端对齐，1.5 倍行距（模板实测约 18 pt），首行缩进 2 个汉字（约 21 pt）。
- 一级标题：四号黑体（14 pt），左对齐；编号形式为 `1`、`2`、`3`。
- 二级标题：五号黑体（10.5 pt），左对齐；编号形式为 `1.1`。
- 三级标题：五号黑体（10.5 pt），左对齐；编号形式为 `1.1.1`。
- “结论”按一级标题排版。
- 不要用手工空格模拟首行缩进、标题编号或对齐；应复制模板中对应层级的示例标题和正文段落。

## 六、表格和表题

- 表题置于表格上方，居中，五号黑体（10.5 pt），格式示例：`表 1 中文图题`。
- 表格内容为五号字（10.5 pt）：中文用宋体，英文和数字用 Times New Roman。
- 单元格文字水平、垂直居中；变量存在单位时必须标明单位。
- 模板示例使用完整网格线。示例表为 3 列，列宽约 3.38 cm、4.17 cm、3.96 cm，总宽约 11.51 cm，并整体居中。
- 新表格应复制模板示例表后增删行列，不要从空白表格重新设置边框、字体和对齐方式。

## 七、参考文献

- “参考文献”标题使用五号黑体（10.5 pt），左对齐。
- 正文引文采用顺序编码制，按首次出现的先后次序连续编号，不得遗漏或颠倒。
- 参考文献列表中的每一篇文献都必须在正文中被引用，并保持编号一一对应。
- 中文参考文献：小五号宋体（9 pt）；英文参考文献：小五号 Times New Roman（9 pt）。
- 文献条目两端对齐，使用悬挂缩进；模板实测悬挂量约 0.50—0.63 cm，行距约 11.5 pt。
- 参考文献格式应直接复制模板中的示例条目后修改，避免手工重新制作编号和悬挂缩进。

## 八、首页脚注信息

首页底部脚注区依次保留并填写：

1. 收稿日期；
2. 基金项目及项目编号；
3. 作者简介（姓名、出生年、籍贯、职称、学位、研究方向、Email）；
4. 通信作者简介及 Email。

脚注文字使用小五号宋体（9 pt），英文、数字和邮箱使用小五号 Times New Roman（9 pt）。若无基金项目等信息，应按投稿要求处理，不要擅自删除整个脚注区。

## 九、完稿检查

- [ ] 工作文件由 `论文模板 (2).doc` 复制而来，不是从空白文档新建。
- [ ] 原始模板未被覆盖或修改。
- [ ] 页面、页边距、字体、字号、行距、缩进和页码均继承模板。
- [ ] 中英文题名、作者、单位、摘要和关键词一一对应。
- [ ] 正文标题编号连续，标题层级没有用手工空格或手工加粗模拟。
- [ ] 图表题位置、字体和编号正确，变量单位完整。
- [ ] 正文引文与参考文献列表编号一一对应。
- [ ] 首页脚注信息填写完整。
- [ ] 红色格式提示、灰底说明和占位方框已从最终投稿稿件中删除。
