> 状态：按照 Lei 等（2022）的 residual edge-GAT 路径模型重新收敛后的设计稿，尚未实现 GAT 训练代码。
> 设计更新日期：2026-08-24。
> 文件名因历史链接保留为 `ppo_transformer_design.md`；当前设计不使用 Transformer。
> 配套调研：[多周期多目标逆向物流与 GAT 神经求解器文献调研](literature_review_gat_reverse_logistics.md)。

## 0. 已确认的设计决定

本文围绕两个核心要求设计：

1. 使用 GAT，MoE 不是必要条件；
2. 使用同一网络结构和同一基础检查点处理不同规模、不同规划期长度和不同成本—风险偏好。

### 0.1 为什么要构建这张图

图输入需要同时完成三件事：

1. 表达问题本身，即有哪些产废任务、处置设施以及节点之间的候选运输关系；
2. 表达当前正在改进的完整计划，即当前期和下一期已经选中了哪些路线边；
3. 表达不可违反的约束和跨期后果，即道路可达性、废物兼容、车辆容量、设施能力、库存结转与期末清空要求。

因此，首版不把“当前路线中已经使用的边”单独当成 GAT 的全部输入。如果只输入当前解子图，网络将看不到尚未使用、但可能用于换边、插入、交换或改变处置设施的候选边。首版也不把车辆编号、时期或未来库存复制成额外节点，以免引入同质车辆的编号对称和随规划期增长的虚拟节点。

### 0.2 输入给神经网络的图是什么

在开始公式化之前，先给出各组成部分的含义：

- **完整候选图**：由全部产废任务节点和处置设施节点构成，并为每一对有序节点保留一条编码边；“有序”表示从 A 到 B 和从 B 到 A 是两个方向不同的连接。
- **当前解子图**：当前计划实际选中的运输边集合。它不是另一套节点，而是通过“当前期是否选中”和“下一期是否选中”两个标记叠加在完整候选图上。
- **硬掩码**：明确告诉策略哪些边或局部修改永远不能选择、哪些在当前库存和路线状态下暂时不能选择。网络只负责在可行动作中评分，不能通过学习绕过硬约束。
- **全局条件**：不属于某一个节点或某一条边、但影响全部决策的信息，包括当前时期、剩余时期、同质车辆容量、可用车辆数上限以及成本—风险偏好。

用 $t$ 表示当前滚动窗口的起始时期。定义以下输入对象后，才写出图的形式：

- $V$：全部任务节点和设施节点的集合；
- $E_{\mathrm{GAT}}$：供 GAT 交换信息的完整有向编码边集合；
- $X_t$：时期 $t$ 下全部节点的特征，包括当前期、下一期和更远时期摘要；
- $Z_t$：时期 $t$ 下全部边的业务特征，包括道路属性、成本、风险和兼容关系；
- $M_t$：时期 $t$ 下的静态与动态硬掩码；
- $Y_t$：当前期和下一期的选中边标记；实现时可以把它拼入 $Z_t$，但概念上单独列出；
- $C_t$：图级全局条件，包括时期、规模、同质车队资源和成本—风险偏好。

于是，一次输入可概括为：

$$
G_t=\left(V,E_{\mathrm{GAT}},X_t,Z_t,M_t,Y_t,C_t\right).
$$

这里的 $G_t$ 是“带有两期库存状态、硬约束和当前解标记的完整候选有向图”。它不是纯道路原图，也不是只保留已选路线边的解图。

首版决定如下。

| 项目 | 首版决定 |
|---|---|
| 图基准 | Lei 式取货任务—设施完全有向图 |
| GAT 节点 | 产生者—废物取货任务、处置设施；不按时期、车辆和路线复制节点 |
| GAT 边 | 单一 `travel` 关系；距离、事故概率、成本、风险和当前路线状态作为边特征 |
| 多废物 | 每个 $(i,s)$ 取货任务对应一个 Lei/CVRP 式需求节点；同类任务共享参数 |
| 周期与库存 | 同一图拓扑上更新当前期、下一期和剩余时域的动态特征 |
| 车辆 | 不输入车辆编号；选中边形成无编号闭合路线，只保留同质车辆容量和可用数量上限 |
| 偏好 | 共享 GAT + 连续偏好条件化 Actor/Critic |
| MoE | 默认关闭；仅作为后续公平消融 |
| 终期库存 | 图中提供紧迫度信息，奖励提供辅助塑形；最终仍由硬掩码、可行性检查和统一检查器保证清零 |
| 泛化主结果 | 一个冻结检查点零样本处理全部测试规模、规划期和偏好 |

首版名称建议为：

> **基于 Lei 式残差边增强 GAT 的多周期偏好条件 PPO 改进器**

英文可写为：

> **A Lei-style Residual Edge-GAT PPO Improver for Multi-period Preference-conditioned Hazardous-waste Routing**

## 1. 问题定义及与现有数学模型的关系

### 1.1 集合

| 符号 | 含义 |
|---|---|
| $I$ | 危险废物产生地点集合 |
| $i$ | 一个具体的产废地点，满足 $i\in I$ |
| $S$ | 废物类型集合 |
| $s$ | 一种具体废物，满足 $s\in S$ |
| $J$ | 处理设施集合 |
| $j$ | 一个具体的处理设施，满足 $j\in J$ |
| $K$ | 现有 MIP 内部使用的同质车辆集合；车辆下标不输入神经网络 |
| $K_t^{\max}$ | 时期 $t$ 最多允许使用的车辆数，也等于该期最多允许形成的闭合路线数；当前车队每期均可用时取 $K_t^{\max}=|K|$ |
| $Q$ | 每辆同质车辆的最大载重量 |
| $T=\{1,\ldots,H\}$ | 离散时期集合 |
| $H$ | 规划期包含的总时期数 |
| $t$ | 任意一个时期；在图输入章节中特指当前滚动窗口的起始时期 |
| $N=I\times S$ | 产生者—废物取货任务集合 |
| $V=N\cup J$ | GAT 节点集合 |
| $E_{\mathrm{GAT}}$ | GAT 信息交换边集合 |
| $\mathcal R_t$ | 当前解在时期 $t$ 中由选中边形成的无编号闭合路线集合 |

与现有 MIP 一致，GAT 把“产生者 $i$ 的废物类型 $s$”定义成一个取货任务节点 $u_{i,s}$，对应内部索引 `n::i::s`。它与 Lei 的 CVRP 客户节点含义相近，但不是一次性订单，也不是每期必须服务的客户；更准确地说，它是跨期持续的“产生者—废物库存账户/可选服务对象”。节点在整个规划期内持续存在，服务后不删除，后续时期可因结余库存和新增废物再次产生取货需求。不同废物类型不会增加网络参数，只会增加使用同一编码器的任务节点数量，因此同一模型可以接收不同 $|I|$ 和 $|S|$。

同一产生者的所有 $u_{i,s}$ 必须共享物理坐标和产生者容量信息；废物库存、风险和兼容属性随 $s$ 不同。节点按废物类型拆分是对真实取货决策粒度的表达，不是按时期复制的虚拟时间节点。同一 $u_{i,s}$ 可在不同期被重复服务；每期访问决策是可选的，按照当前 MIP，它在同一期最多出现在一条闭合路线中，一旦访问就收走该期全部可收库存。后文用 $BG_{i,s,t}$ 表示任务 $(i,s)$ 在时期 $t$ 的全部可收库存。

当前模型没有独立车场。处置设施同时是路线锚点。用 $m$ 表示一条路线访问的任务数，用 $i_1,\ldots,i_m$ 表示这些任务对应的产废地点，用 $s_1,\ldots,s_m$ 表示相应废物类型，则路线形式为：

$$
j\rightarrow u_{i_1,s_1}\rightarrow u_{i_2,s_2}\rightarrow\cdots\rightarrow u_{i_m,s_m}\rightarrow j,
\qquad j\in J.
$$

如果以后增加独立车场，再把车场作为第三类路径节点；首版不预先增加。

### 1.2 成本—风险目标

先定义目标中的符号：

- $f_c$：一个完整可行方案的总成本；
- $f_r$：同一方案的总风险；
- $b_c$：成本的正归一化尺度；
- $b_r$：风险的正归一化尺度；
- $\widehat f_c$：归一化后的成本；
- $\widehat f_r$：归一化后的风险。

成本和风险分别按稳定的实例内尺度归一化：

$$
\widehat f_c=\frac{f_c}{b_c},
\qquad
\widehat f_r=\frac{f_r}{b_r}.
$$

再定义 $\alpha_c$ 为成本偏好权重，$\alpha_r$ 为风险偏好权重，并把二者组成偏好向量 $\boldsymbol\alpha$：

$$
\boldsymbol\alpha=(\alpha_c,\alpha_r),
\qquad
\alpha_c+\alpha_r=1,
\qquad
\alpha_c,\alpha_r\ge 0.
$$

最后用 $J_{\boldsymbol\alpha}$ 表示偏好 $\boldsymbol\alpha$ 下需要最小化的单目标值。模型只在严格可行解集合中比较：

$$
J_{\boldsymbol\alpha}
=\alpha_c\widehat f_c+\alpha_r\widehat f_r.
$$

训练轨迹始终分别保存成本和风险，不能只保留提前加权后的单个标量。

### 1.3 硬约束

- 路线从某一处置设施出发并返回同一设施；
- 每个已访问任务必须恰有一条选入边和一条选出边；从设施的每条已选出边开始，沿任务的唯一后继必须回到同一设施，且不能存在与设施脱离的任务子回路；
- 时期 $t$ 的闭合路线数量不能超过 $K_t^{\max}$；MIP 可在求解或输出时把这些路线任意分配给同质车辆下标；
- 同一 $(i,s)$ 取货任务在同一期最多出现在一条路线中，但可跨期重复服务；
- 每条路线的总取货量不能超过同质车辆容量 $Q$；
- 车载废物满足共载兼容矩阵；
- 路线设施能够处理车上全部废物；
- 设施存储量和处理量不超限；
- 产生者库存和设施库存逐期守恒；
- 已提交时期不可被后续窗口修改；
- `require_terminal_clear=true` 时，最终产生者和设施库存严格为零。

可行性约束先于成本—风险偏好，任何偏好都不能补偿硬约束违反。

## 2. 为什么以 Lei 为基准

Lei 等在 CVRP 中采用“仓库/客户节点 + 完全有向边 + 距离边属性 + 车辆解码状态”。本项目保留其节点、完全图和边增强注意力设计，但针对“需求不可拆分、车辆同质、已有完整解再改进”的特点，不复制 Lei 的逐车构造式解码状态。从设施的一条已选出边开始，沿每个任务的唯一后继边追踪并回到同一设施，就得到一条无编号路线。

| 组成 | Lei 的 CVRP | 本项目的对应设计 |
|---|---|---|
| 路径节点 | 仓库、客户 | 处置设施、产生者—废物取货任务 |
| 图连接 | 完全有向图 | 完全有向编码图 |
| 基础边属性 | 距离 | 距离、事故概率、运输成本和风险 |
| 客户需求 | 当前需求 | 对应 $(i,s)$ 的当前库存、产生量和未来义务 |
| 仓库 | 单仓库 | 多个可选处置设施，同时承担路线起终点 |
| 车辆 | 构造式解码中的剩余容量状态 | 不输入车辆编号；使用无编号路线负载、路线容量余量和全局路线数上限 |
| 时间 | 单期 | 当前/下一期动态特征 + 剩余时域摘要 |
| 多目标 | 单目标 | 成本—风险偏好条件 |
| 期末约束 | 无 | 库存清零硬约束 + 奖励塑形 |

这里的扩展发生在节点特征、边特征、解码上下文和环境约束中，不通过大量新增虚拟节点实现。

## 3. 节点定义

### 3.1 只有两类路径节点

用 $V^N$ 表示全部取货任务节点的集合，用 $V^F$ 表示全部处置设施节点的集合；二者并集是完整节点集合 $V$：

$$
V=V^N\cup V^F,
\qquad
V^N=\{u_{i,s}:i\in I,s\in S\},
\qquad
V^F=\{d_j:j\in J\}.
$$

- `pickup_task` 节点 $u_{i,s}$：位于产废地点 $i$、需要收集废物 $s$ 的服务任务；
- `facility` 节点 $d_j$：一个实际处置设施，同时是车辆可选起终点。

因此：

$$
|V|=|I||S|+|J|.
$$

任务节点数量可变，但所有 $u_{i,s}$ 使用同一个节点编码器。它们不按时期复制，所以 $H$ 增大不会增加 GAT 节点数；同一节点只更新当前库存、未来产生量和计划访问等动态特征。同一产生者的不同任务共享坐标、产生者容量和同址总库存特征。

以下对象不建立 GAT 节点：

- 时期和双期窗口；
- 车辆或车辆—时期组合；
- 当前路线边和插入位置；
- 未来废物与未来设施能力；
- 成本目标、风险目标或偏好节点。

### 3.2 为什么不把不同废物拼成固定向量

若把 $|S|$ 个废物库存直接拼进一个产废点向量，输入维度会随 $|S|$ 变化；把 $(i,s)$ 作为任务节点后，输入维度固定，废物类型数只改变节点数量。这与 Lei 中“客户数变化但每个客户的需求特征维度固定”的处理一致。

废物类型通过后果、库存风险、处理需求和兼容关系等属性表达。若只使用训练集专属的绝对类型 ID，则只能宣称对不同任务数量泛化，不能宣称对未见废物属性泛化。

### 3.3 取货任务节点特征

任务节点 $u_{i,s}$ 的静态特征：

- 节点类型标志；
- 产生者 $i$ 的坐标或区域特征；
- 产废点总存储容量；
- 废物 $s$ 的后果和库存风险属性；
- 不使用跨实例绝对 producer ID 或 waste ID。

动态特征使用以下库存符号：

- $I^P_{i,s,t-1}$：时期 $t$ 开始前，产废地点 $i$ 尚未运走的废物 $s$ 库存；上标 $P$ 表示 producer，即产废端；
- $g_{i,s,t}$：产废地点 $i$ 在时期 $t$ 新产生的废物 $s$ 数量；
- $BG_{i,s,t}$：时期 $t$ 加入新增产生量后可供收运的全部废物，满足 $BG_{i,s,t}=I^P_{i,s,t-1}+g_{i,s,t}$；
- $C_i^P$：产废地点 $i$ 的库存容量；
- $\tau$：求和式中的时期游标，只用于遍历未来时期，不表示新的节点。

动态特征包含：

| 类别 | 建议特征 |
|---|---|
| 当前库存 | 上期末库存 $I^P_{i,s,t-1}$、本期产生量 $g_{i,s,t}$、本期可收量 $BG_{i,s,t}$ |
| 下一期 | $g_{i,s,t+1}$、当前计划下的下一期期初库存 |
| 剩余时域 | $\sum_{\tau>t+1}g_{i,s,\tau}$、剩余总义务、最迟服务松弛 |
| 容量 | 分类型库存占比、同址总库存占比、存储剩余比例 |
| 风险 | 废物后果、产生者库存风险系数 |
| 当前解 | 当前期/下一期是否计划访问、计划取货量 |

连续量使用容量或实例尺度归一化，例如：

$$
\frac{I^P_{i,s,t-1}}{C_i^P},
\quad
\frac{BG_{i,s,t}}{C_i^P},
\quad
\frac{\sum_{\tau>t}g_{i,s,\tau}}{C_i^P},
\quad
\frac{H-t}{H}.
$$

### 3.4 设施节点特征

处置设施 $j$ 的静态特征：

- 节点类型标志；
- 坐标或区域特征；
- 总存储容量；
- 是否开放。

设施节点的动态聚合特征包含：

| 类别 | 建议特征 |
|---|---|
| 当前库存 | 跨废物总库存率、本期总预计接收率、处理前总库存率 |
| 处理能力 | 当期/下一期总处理利用率、剩余时域总能力比 |
| 容量松弛 | 总存储剩余比例、各废物能力松弛的最小值 |
| 当前解 | 当前期/下一期接收路线数和总接收量 |

针对具体废物 $s$ 的设施库存、技术、处理成本、库存风险和处理能力放在 $u_{i,s}\leftrightarrow d_j$ 的条件边特征中，避免设施节点输入维度随 $|S|$ 变化。

## 4. 边定义与联通关系

### 4.1 编码图与实际运输动作必须分开

先定义符号：$u$ 和 $v$ 表示节点集合 $V$ 中任意两个节点，$(u,v)$ 表示从 $u$ 指向 $v$ 的有向边。按照 Lei 的做法，GAT 编码图使用完全有向图：

$$
E_{\mathrm{GAT}}=V\times V.
$$

其中 $V\times V$ 表示全部有序节点对。实现时保留 $u=v$ 的自环供消息传递；完全图表示“节点之间可以交换信息”，不表示所有边都可以成为运输路线。

运输可行性分成两层：

- **静态边掩码**：用 $M_{uv}^{\mathrm{static}}$ 表示边 $u\rightarrow v$ 在业务模型中是否可能成为运输边。取值 1 表示结构上允许，取值 0 表示永久禁止。道路完全不可达、设施—设施转运、同址任务直连和自环运输属于静态禁止。
- **动态动作掩码**：先用 $a$ 表示一次候选局部修改，例如把任务插入另一条路线、交换两个任务或改变路线设施；再用 $M_{a,t}^{\mathrm{dynamic}}$ 表示动作 $a$ 在时期 $t$ 的当前解上是否可行。路线容量、整条路线共载兼容、设施剩余能力和期末可承接性属于动态检查。

文中总掩码 $M_t$ 是上述静态边掩码和动态动作掩码的统称。编码边和运输动作分离，可以同时保持 Lei 式完全图和本问题的业务约束。非法动作在策略 softmax 前把得分设为 $-\infty$，所以不会被抽样。

定义 $E_t^{\mathrm{sol}}$ 为当前方案在时期 $t$ 实际选中的运输边集合。它是 $E_{\mathrm{GAT}}$ 的子集。严格可行时，每个已访问任务恰有一个前驱和一个后继；从设施的每条已选出边开始，沿任务后继连续追踪并回到同一设施，就得到一条闭合回路。不同路线的运输边互不重复，但可以共享同一个设施节点；这些闭合回路构成无编号路线集合 $\mathcal R_t$。

### 4.2 实际运输联通规则

| 起点 | 终点 | 动作何时允许 |
|---|---|---|
| 处置设施 $d_j$ | 取货任务 $u_{i,s}$ | 车辆开始路线；道路可达；设施技术能够处理 $s$，并能承接该路线随后收集的废物 |
| 取货任务 $u_{i,s}$ | 取货任务 $u_{i',s'}$ | $i\ne i'$；道路可达；车辆剩余容量足够；$s'$ 与当前载荷兼容 |
| 取货任务 $u_{i,s}$ | 同址任务 $u_{i,s'}$ | 当前 MIP 禁止同一产生者任务间直连，因此运输动作永久屏蔽；编码边仍保留以交换同址库存信息 |
| 取货任务 $u_{i,s}$ | 处置设施 $d_j$ | 道路可达；设施能处理车上全部废物；存储和剩余处理能力可承接 |
| 处置设施 $d_j$ | 处置设施 $d_{j'}$ | 当前模型不允许设施间转运，因此永久屏蔽；只有业务模型改变后才开放 |
| 任意节点 $u$ | 自身 $u$ | 仅用于 GAT 自环，永久禁止作为运输动作 |

同一条路线必须从设施 $d_j$ 出发并回到同一设施 $d_j$。这一规则由路线状态机和动作掩码保证，不通过额外“闭环节点”表达。

### 4.3 基础边特征

所有有向边共享同一个边编码器。先定义基础字段：

- $d_{uv}$：从节点 $u$ 到节点 $v$ 的道路距离；
- $\mathrm{time}_{uv}$：从 $u$ 到 $v$ 的行驶时间；
- $p^{\mathrm{acc}}_{uv}$：从 $u$ 到 $v$ 的道路事故概率；
- $c^{\mathrm{travel}}_{uv}$：从 $u$ 到 $v$ 的基础运输成本；
- $r^{\mathrm{base}}_{uv}$：只由道路暴露决定、尚未乘入具体车载废物后果的基础风险；
- $d_{\mathrm{scale}}$ 和 $t_{\mathrm{scale}}$：距离与时间的正归一化尺度；
- $b_c^{\mathrm{edge}}$ 和 $b_r^{\mathrm{edge}}$：边成本与边风险的正归一化尺度；
- $\mathbf 1_{\mathrm{road\ feasible}}$：道路可达时为 1，完全不可达时为 0；
- $\mathbf 1_{\mathrm{same\ producer}}$：两个任务属于同一产废企业时为 1，否则为 0；
- $\mathrm{typepair}(u,v)$：起点类型和终点类型的编码，例如“设施→任务”或“任务→设施”。

把这些字段按固定顺序拼接，得到基础边特征 $z^{\mathrm{base}}_{uv}$：

$$
z^{\mathrm{base}}_{uv}
=\left[
\frac{d_{uv}}{d_{\mathrm{scale}}},
\frac{\mathrm{time}_{uv}}{t_{\mathrm{scale}}},
p^{\mathrm{acc}}_{uv},
\frac{c^{\mathrm{travel}}_{uv}}{b_c^{\mathrm{edge}}},
\frac{r^{\mathrm{base}}_{uv}}{b_r^{\mathrm{edge}}},
\mathbf 1_{\mathrm{road\ feasible}},
\mathbf 1_{\mathrm{same\ producer}},
\mathrm{typepair}(u,v)
\right].
$$

边是有方向的：即使距离对称，事故概率、行驶时间和区域风险也可以不对称。随实际路线载荷和废物后果变化的运输风险在动作评分时计算。

再定义 $z^{\mathrm{cond}}_{uv,t}$ 为时期 $t$ 下、随节点对类型变化的条件边特征。它仍属于同一个 `travel` 边向量，不增加关系类型：

| 节点对 | 非零条件字段 |
|---|---|
| $u_{i,s}\leftrightarrow u_{i',s'}$ | $\mathrm{compatibility}_{s,s'}$、共载风险系数、是否同一产生者 |
| $u_{i,s}\leftrightarrow d_j$ | $\mathrm{technology}_{j,s}$、处理成本、设施库存风险、$s$ 的当前库存率、当期/下一期/剩余处理能力松弛 |
| $d_j\leftrightarrow d_{j'}$ | 当前业务无转运，条件字段置零并设置 `route_allowed=0` |

不适用于某类节点对的字段置零。另用 $m^{\mathrm{app}}_{uv}$ 表示各条件字段是否适用于节点对 $(u,v)$，避免“数值恰好为零”和“该字段不适用”混淆。

最后定义当前解标记。若时期 $t$ 的当前方案选中了边 $u\rightarrow v$，则令 $y_{uv,t}=1$；否则令 $y_{uv,t}=0$。全部 $y_{uv,t}$ 组成概念上的当前解标记 $Y_t$。当前两期窗口同时保留 $y_{uv,t}$ 和 $y_{uv,t+1}$，并把它们追加到最终边特征 $z_{uv,t}$：

$$
z_{uv,t}
=z^{\mathrm{base}}_{uv}
\Vert z^{\mathrm{cond}}_{uv,t}
\Vert m^{\mathrm{app}}_{uv}
\Vert
\left[
y_{uv,t},
y_{uv,t+1}
\right].
$$

因此，完整候选图中的一条边可以被明确区分为“当前已选”“当前未选但可行”或“永久不可用”。边向量不设置车辆编号槽位；当前路线归属通过“从设施已选出边出发并沿任务唯一后继追踪”的确定性过程恢复。

### 4.4 当前解与动作候选特征

由于本方法是局部改进器，还需要以下动态候选特征：

- 该弧是否出现在当前期或下一期方案中；
- 选择该弧后的增量距离、增量成本和增量风险；
- 对目标无编号路线而言是否满足容量和共载兼容；
- 对返回设施而言是否满足处理技术、存储和剩余处理能力；
- 该动作是否破坏剩余时域可承接性。

这些特征由 Actor 的候选动作评分器使用，不建立 `route_edge` 节点。下面先定义评分公式中使用的量：

- $h_u$ 和 $h_v$：GAT 编码后节点 $u$ 和节点 $v$ 的表示；
- $\rho$：当前选中边形成的一条无编号闭合路线；需要新建路线时使用专门的空路线占位，不使用空闲车辆编号；
- $c_{t,\rho,\alpha}$：时期 $t$、路线 $\rho$ 和成本—风险偏好 $\alpha$ 共同形成的候选上下文；
- $z_{uv,t}$：前述时期 $t$ 的有向边特征；
- $\Delta c_{uv}$ 和 $\Delta r_{uv}$：候选修改引起的成本增量和风险增量。
- $\operatorname{MLP}_{\mathrm{candidate}}$：所有候选动作共享参数的前馈评分网络。

候选评分可以写为：

$$
\operatorname{score}(u,v\mid t,\rho,\alpha)
=\operatorname{MLP}_{\mathrm{candidate}}
\left[
h_u\Vert h_v\Vert c_{t,\rho,\alpha}\Vert z_{uv,t}
\Vert\Delta c_{uv}\Vert\Delta r_{uv}
\right].
$$

设施技术、废物兼容和能力松弛已经按任务—设施或任务—任务节点对写入 $z_{uv,t}$，同时仍由硬掩码作最终判定。

## 5. 周期与库存如何进入同一张图

### 5.1 图拓扑不随时期复制

对所有时期使用同一任务—设施拓扑。第 0.2 节已经定义完整输入 $G_t$ 的七个组成部分，其中节点集合 $V$ 和编码边集合 $E_{\mathrm{GAT}}$ 保持不变；节点特征 $X_t$、边特征 $Z_t$、掩码 $M_t$、当前解标记 $Y_t$ 和全局条件 $C_t$ 随窗口状态更新：

$$
G_t=\left(V,E_{\mathrm{GAT}},X_t,Z_t,M_t,Y_t,C_t\right).
$$

实现时允许把 $Y_t$ 拼入 $Z_t$，也允许把 $C_t$ 在 GAT 池化后再送给 Actor/Critic；上式强调的是信息组成，不要求七个对象必须作为七个独立张量。图节点数由 $|I||S|+|J|$ 决定，不随总时期数 $H$ 成倍增长。

### 5.2 双期窗口仍保留，但不产生时期节点

用 $\mathcal W_t$ 表示起始于时期 $t$ 的滚动窗口。当总时期数 $H=1$ 时只有单期窗口：

$$
\mathcal W_1=\{1\}.
$$

当 $H\ge2$ 时，窗口起点只取 $t=1,\ldots,H-1$：

$$
\mathcal W_t=\{t,t+1\},
\qquad t=1,\ldots,H-1.
$$

每个任务/设施节点同时放入当前期和下一期的固定槽位特征；更远时期压缩为累计产生量、累计处理能力、最小松弛和最迟服务紧迫度。只有 $H=1$ 时下一期槽位置零并使用 `next_period_exists=0` 标记；$H\ge2$ 时不存在单独的 $\mathcal W_H$。

对 $t<H-1$，窗口推进时只提交时期 $t$，时期 $t+1$ 作为下一窗口热启动；最后窗口 $\mathcal W_{H-1}=\{H-1,H\}$ 联合提交最后两个时期。$H=1$ 时直接提交唯一时期。

### 5.3 全局条件和无编号路线状态

不设置 `period` 或 `horizon_context` 节点。先定义全局条件中使用的量：

- $H$：总时期数；$t$：当前窗口起始时期；
- $|I|$、$|J|$、$|S|$：产废企业数、设施数和废物类型数；
- $K_t^{\max}$：时期 $t$ 最多允许形成的闭合路线数；
- `global capacity slack`：剩余时期可用总运输能力和总处理能力相对于剩余废物义务的无量纲余量；
- $\mathbf 1_{\mathrm{last\ window}}$：当前为最后一个两期窗口时取 1，否则取 0。

将这些量拼接并记为全局条件 $c_t^{\mathrm{global}}$：

$$
c_t^{\mathrm{global}}
=\left[
\frac{t}{H},
\frac{H-t}{H},
\mathbf 1_{\mathrm{last\ window}},
\log(1+|I|),
\log(1+|J|),
\log(1+K_t^{\max}),
\log(1+|S|),
\mathrm{global\ capacity\ slack}
\right].
$$

本方法改进的是完整计划路线，不模拟某辆带编号车辆正在道路上逐点行驶。按照第 4.1 节的确定性追踪方法，当前期被选中的运输边恢复成闭合路线集合 $\mathcal R_t$。用 $\rho$ 表示其中任意一条路线，并定义：

- $L_{t,\rho}$：时期 $t$ 中路线 $\rho$ 收集的全部废物量；
- $Q$：每辆同质车辆的容量，所以 $(Q-L_{t,\rho})/Q$ 是路线容量剩余比例；
- $h_u$：GAT 输出的节点 $u$ 表示；
- $\operatorname{Pool}_{u\in\rho}h_u$：对路线 $\rho$ 上所有任务节点表示进行与顺序无关的池化；
- `planned waste properties`：路线中已计划装载废物的后果、兼容性和风险属性汇总；
- `empty route`：新建路线时使用的统一空路线占位。它只表示“再开一条路线”的候选，不对应某个空闲车辆编号。
- $\operatorname{MLP}_{\mathrm{route}}$：所有无编号路线共享参数的前馈网络。

据此构造无编号路线表示 $h_{t,\rho}^{\mathrm{route}}$：

$$
h_{t,\rho}^{\mathrm{route}}
=\operatorname{MLP}_{\mathrm{route}}
\left[
\frac{Q-L_{t,\rho}}{Q},
\operatorname{Pool}_{u\in\rho}h_u,
\operatorname{Pool}(\mathrm{planned\ waste\ properties}_{t,\rho}),
\mathbf 1_{\mathrm{empty\ route}}
\right].
$$

候选插入或切分位置由有序端点 $u,v$ 及其节点表示表达。网络不能输入裸车辆 ID、持久路线 ID 或裸节点 ID；实现中的路线句柄只用于定位当前选中边分量，不能作为可学习特征。成本—风险偏好另行编码，最终与图表示、全局条件和无编号路线表示拼接。路线数量变化只改变候选集合大小，不改变网络参数和输出层形状。

### 5.4 必须保持的库存语义

库存由确定性环境传播，不能只让网络估计。先定义产废端使用的量：

- $I^P_{i,s,t-1}$：时期 $t$ 开始前产废地点 $i$ 的废物 $s$ 库存；
- $g_{i,s,t}$：时期 $t$ 的新增产生量；
- $BG_{i,s,t}$：时期 $t$ 可收运总量；
- $q_{i,s,k,t}$：现有 MIP 中车辆 $k$ 在时期 $t$ 从任务 $(i,s)$ 收取的数量；车辆下标 $k$ 只用于数学模型记账，不输入神经网络；
- $I^P_{i,s,t}$：时期 $t$ 结束后的产废端库存。

当前数学模型在每期先加入产生量：

$$
BG_{i,s,t}=I^P_{i,s,t-1}+g_{i,s,t},
$$

再执行取货并结转：

$$
I^P_{i,s,t}
=BG_{i,s,t}-\sum_k q_{i,s,k,t}.
$$

设施端使用以下量：

- $I^F_{j,s,t-1}$：时期 $t$ 开始前设施 $j$ 中废物 $s$ 的库存；上标 $F$ 表示 facility，即设施端；
- $R_{j,s,t}$：时期 $t$ 由所有闭合路线运入设施 $j$ 的废物 $s$ 总量；
- $BD_{j,s,t}$：本期处理前的设施可处理总量；
- $P_{j,s,t}$：时期 $t$ 在设施 $j$ 实际处理的废物 $s$ 数量；
- $I^F_{j,s,t}$：时期 $t$ 结束后的设施库存。

设施端满足：

$$
BD_{j,s,t}=I^F_{j,s,t-1}+R_{j,s,t},
$$

$$
I^F_{j,s,t}=BD_{j,s,t}-P_{j,s,t}.
$$

GAT 只能收集截至当前时期已经产生的废物，不能提前运输未来产生量。库存状态在每次候选动作后由确定性环境重新传播，不能只由网络自行估计。

## 6. 周期末端库存约束

### 6.1 期末约束不改变节点和边

当 `require_terminal_clear=true` 时：

$$
I^P_{i,s,H}=0,
\qquad \forall i,s,
$$

$$
I^F_{j,s,H}=0,
\qquad \forall j,s.
$$

它是规划期边界条件，不是某两个物理地点之间的关系，因此不新增“末期节点”或“末期边”。

### 6.2 在表示中提供末端压力

虽然不改变图结构，仍应向策略提供以下信息：

- 当前期和剩余期数；
- 各产废点剩余库存与未来累计产生量；
- 各设施剩余时域累计处理能力；
- 剩余车辆总运力；
- 最迟服务期和处理能力松弛；
- `is_last_window` 标志。

这些信号分别进入取货任务节点、设施节点/任务—设施条件边和全局上下文。它们帮助策略提前行动，但本身不等同于约束保证。

### 6.3 奖励塑形可以使用，但不能单独改变可行域

简单使用“产生者库存 + 设施库存”会在废物由产生者搬到设施时近似守恒，无法形成有效塑形。因此分别设置产废库存、设施库存、截止期和能力松弛项：

$$
\Phi_t
=\lambda_P(t)\sum_{i,s}\widehat I^P_{i,s,t}
+\lambda_F(t)\sum_{j,s}\widehat I^F_{j,s,t}
+\lambda_D\widehat D_t
+\lambda_C[-s_t^{\mathrm{proc}}]_+
+\lambda_V[-s_t^{\mathrm{veh}}]_+,
$$

其中 $\widehat D_t$ 是最迟服务期压力或违约量，$s_t^{\mathrm{proc}}$ 和 $s_t^{\mathrm{veh}}$ 分别为剩余处理能力、车辆运力松弛。应设置 $\lambda_P(t)>\lambda_F(t)$，使把库存从产生者收至设施获得阶段性正信号；设施库存只有被实际处理后才进一步下降。$\lambda_P(t)$、$\lambda_F(t)$ 随 $t/H$ 增强。

势函数奖励在候选动作完成确定性库存传播后计算：

$$
r_t^{\mathrm{terminal\ shape}}
=\Phi_{\mathrm{before}}-\Phi_{\mathrm{after}}.
$$

最终库存未清零时给予独立终端失败惩罚。但若接受“付出惩罚后仍有库存”的方案，就等于改变原数学模型。因此首版不能只靠有限惩罚判断可行性。

### 6.4 首版采用的硬保障

1. 动作掩码禁止越过最迟服务期或明显破坏剩余运力/处理能力必要条件的动作；
2. 窗口提交前运行剩余时域可行性预检和确定性补全；
3. 最后两至三期必要时调用保留的 MILP 做修复；
4. 最终方案统一调用 `check_solution`，必须满足 $I^P_H=I^F_H=0$；
5. 修复失败则返回历史最佳严格可行 incumbent，不输出伪可行解。

“只使用奖励处理末期库存”保留为消融实验 `terminal_penalty_only`，用于验证硬保障的必要性，不作为正式模型。

## 7. Lei 式残差 Edge-GAT 编码器

### 7.1 共享节点和边投影

取货任务和设施特征先整理为同一固定维输入，未适用字段置零，并加入节点类型标志。公式中的量定义如下：

- $x_u$：节点 $u$ 的原始输入特征；
- $z_{uv,t}$：时期 $t$ 中有向边 $u\rightarrow v$ 的最终输入特征；
- $h_u^{(0)}$：节点 $u$ 投影后的初始隐藏表示；
- $\widehat z_{uv,t}$：边特征投影后的隐藏表示；
- $A_0,A_1$ 和 $b_0,b_1$：可训练的线性变换矩阵和偏置；
- $\operatorname{BN}$：批归一化操作。

按照 Lei 原文，节点与当前动态边分别经线性层和归一化：

$$
h_u^{(0)}=\operatorname{BN}(A_0x_u+b_0),
\qquad
\widehat z_{uv,t}=\operatorname{BN}(A_1z_{uv,t}+b_1).
$$

首版只有一种 `travel` 关系，不使用十种关系专属参数，也不对时期和车辆设置节点投影。边嵌入在各 GAT 层中保持不变，与 Lei 的基准实现一致。

### 7.2 边特征参与注意力

先定义注意力公式中的符号：

- $\ell$：GAT 的层编号；
- $h_u^{(\ell-1)}$：进入第 $\ell$ 层前节点 $u$ 的表示；
- $\alpha_{uv}^{(\ell)}$：第 $\ell$ 层中节点 $u$ 分配给节点 $v$ 的注意力权重；
- $g^\ell$、$W^\ell$ 和 $W_1^\ell$：第 $\ell$ 层可训练参数；
- $w$：注意力分母中遍历全部节点时使用的临时节点符号；
- $\sigma$：LeakyReLU 激活函数；
- $\Vert$：向量拼接。

对第 $\ell$ 层，节点 $u$ 对节点 $v$ 的 Lei 式注意力为：

$$
\alpha_{uv}^{(\ell)}
=\frac{
\exp\!\left(
\sigma\!\left(
(g^{\ell})^\top W^\ell
[h_u^{(\ell-1)}\Vert h_v^{(\ell-1)}\Vert\widehat z_{uv,t}]
\right)\right)}{
\sum_{w\in V}\exp\!\left(
\sigma\!\left(
(g^{\ell})^\top W^\ell
[h_u^{(\ell-1)}\Vert h_w^{(\ell-1)}\Vert\widehat z_{uw,t}]
\right)\right)},
$$

再把所有邻居信息按注意力权重聚合，并与上一层节点表示相加，得到残差节点更新：

$$
h_u^{(\ell)}
=h_u^{(\ell-1)}
+\sum_{v\in V}\alpha_{uv}^{(\ell)}W_1^\ell h_v^{(\ell-1)}.
$$

首版先采用 4 层、单注意力系数、残差 E-GAT，尽量复现 Lei 的编码器逻辑。多头 E-GAT、LayerNorm/FFN 和 GATv2 都作为后续消融，不能写入“Lei 基准”结果中。

### 7.3 图级表示

先分别对取货任务和设施做 mean pooling，得到与具体路线及偏好无关的图表示。这里 $V^N$ 是全部取货任务节点集合，$J$ 是全部设施集合，$h_u$ 和 $h_j$ 分别是任务节点与设施节点的 GAT 输出；$\operatorname{mean}$ 表示集合内均值池化，$\Vert$ 表示向量拼接，$\operatorname{MLP}_g$ 表示用于生成图级表示的共享前馈网络：

$$
g_t^{\mathrm{graph}}
=\operatorname{MLP}_g
\left[
\operatorname{mean}_{u\in V^N}h_u
\Vert\operatorname{mean}_{j\in J}h_j
\right].
$$

成本—风险偏好经过编码后记为 $p_\alpha$。把图表示 $g_t^{\mathrm{graph}}$、第 5.3 节定义的全局条件 $c_t^{\mathrm{global}}$、无编号路线表示 $h_{t,\rho}^{\mathrm{route}}$ 和偏好表示 $p_\alpha$ 拼接，得到路线候选上下文：

$$
c_{t,\rho,\alpha}
=g_t^{\mathrm{graph}}
\Vert c_t^{\mathrm{global}}
\Vert h_{t,\rho}^{\mathrm{route}}
\Vert p_\alpha.
$$

其中 $\rho$ 是当前选中边形成的一条闭合路线，或统一的空路线占位。GAT 图编码不依赖车辆编号，也不随成本—风险偏好重复计算。显式规模特征位于 $c_t^{\mathrm{global}}$，用于补回 mean pooling 丢失的计数信息。

## 8. PPO 局部改进动作

### 8.1 总体流程

GAT-PPO 从 GA、启发式或小规模 MILP 生成的完整可行解出发：

```text
完整可行初始解
→ 构造 Lei 式任务—设施完全图
→ 更新当前/下一期库存特征和当前方案状态
→ residual edge-GAT 编码
→ 偏好条件 Actor 选择时期、算子、无编号闭合路线和任务/设施节点及路线位置
→ 硬掩码、库存传播与确定性修复
→ 剩余时域可行性预检
→ rollout 可接受严格可行且可补全的中间状态
→ 仅当完整方案优于 incumbent 时更新最佳解
→ 最终严格检查期末库存并返回最佳可行解
```

### 8.2 动作分解

动作公式中的符号先定义如下：

- $a$：一次完整的局部修改动作；
- $o$：局部算子类型，例如移动、交换、2-opt 或改变设施；
- $\delta t$：时期偏移量，取 0 表示当前期，取 1 表示下一期；
- $\rho$：被修改的无编号闭合路线；需要新建路线时取统一空路线占位；
- $u,v$：动作涉及的任务节点或设施节点；
- $\ell$：路线中的具体位置记录，由时期、当前路线句柄、位置序号和该位置前后的有向端点组成。路线句柄只服务于环境定位，不作为神经网络的身份嵌入。

动作写为：

$$
a=(o,\delta t,\rho,u,v,\ell).
$$

任务节点 $u_{i,s}$ 已经同时确定产废企业 $i$ 和废物类型 $s$。时期、无编号路线和路线位置都是解码候选或动作属性，不加入 GAT 节点集合，因此不需要 `vehicle` 或 `route_edge` 节点。

### 8.3 首版算子

| 算子 | 任务—设施图上的含义 |
|---|---|
| `relocate_in_period` | 把某 $(i,s)$ 在该期的一次计划访问及取货量移到另一条无编号路线或另一弧位置 |
| `swap_in_period` | 交换同一期两个任务的计划访问位置 |
| `two_opt_route` | 选择两条有序路线弧并反转中间片段；重建反转后的全部内部有向弧 |
| `change_facility` | 改变一条闭合路线的起终点设施 |
| `reschedule_between_periods` | 将同一 $(i,s)$ 的某次计划访问及可行取货量改排到相邻时期，不在两套时期节点之间移动 |

跨期动作只能处理当前已经产生的库存；未来产生量仍保留在后续时期。

### 8.4 分层硬掩码

1. 时期掩码：冻结时期和不存在的下一期不可选；
2. 路线掩码：目标闭合路线的容量、当前载荷和路线数上限；新建路线后总路线数不得超过 $K_t^{\max}$；
3. 节点掩码：取货任务是否有可收库存、是否超过最迟服务期；
4. 弧掩码：道路、自环、设施间转运和闭环规则；
5. 废物掩码：共载兼容、设施技术、存储和处理能力；
6. 终端掩码：剩余时域是否仍可能完成库存清零。

非法动作 logits 在 softmax 前设为 $-\infty$。
由于距离、事故概率和道路可达性可以不对称，`two_opt_route` 的掩码与增量评价必须检查反转片段的全部内部反向弧，不能只检查两条切分弧。

## 9. 连续偏好与 PPO 目标

### 9.1 偏好条件化

偏好编码：

$$
p_\alpha
=\operatorname{MLP}_\alpha
\left[
\alpha_c,\alpha_r,
\sin(\pi\alpha_c),\cos(\pi\alpha_c),
\sin(2\pi\alpha_c),\cos(2\pi\alpha_c)
\right].
$$

共享 GAT 不因偏好改变参数。Actor 和 Critic 使用 FiLM 或门控接收 $p_\alpha$。Critic 输出成本和风险两个分量：

$$
V_\theta(s,\boldsymbol\alpha)
=\left[V_c(s,\boldsymbol\alpha),V_r(s,\boldsymbol\alpha)\right].
$$

### 9.2 二维回报

$$
r_t^c
=\widehat f_{c,\mathrm{before}}
-\widehat f_{c,\mathrm{after}},
$$

$$
r_t^r
=\widehat f_{r,\mathrm{before}}
-\widehat f_{r,\mathrm{after}}.
$$

给定偏好：

$$
r_t^\alpha
=\alpha_cr_t^c+\alpha_rr_t^r
+r_t^{\mathrm{terminal\ shape}}
-P_t^{\mathrm{feas}}.
$$

末端塑形与偏好无关，避免风险权重较低时削弱硬约束信号。PPO 的目标优势在成本/风险优势之外单独加入末端塑形和可行性信号；无效动作、补全失败和终端失败分别记录，不能混入成本或风险原始定义。

### 9.3 MoE

首版不使用 MoE。只有共享模型在公平参数量和训练预算下确实出现偏好冲突或 Pareto 覆盖坍缩时，才在 Actor 后端增加小型专家作为消融；GAT 主干始终共享。

## 10. 泛化设计

### 10.1 一个模型的严格定义

- 同一网络结构和同一组基础参数；
- 不因 $|I|,|J|,|K|,|S|,H$ 或偏好重新初始化；
- 任务节点数量、完整边数量和动作候选数量可以变化；
- 主结果推理时冻结参数；
- 测试时适应必须单独报告。

### 10.2 联合训练分布

训练 episode 联合随机化：

- 产生者、设施、车辆、废物类型和时期数量；
- 空间分布和有向风险分布；
- 初始库存、产生量峰值和库存容量；
- 车辆、设施和处理能力紧度；
- 技术矩阵和共载兼容矩阵；
- 成本—风险连续偏好；
- 初始解来源和质量。

批次损失按实例等权，避免完整图中的大实例仅因边数多而支配梯度。

### 10.3 测试层次

| 层次 | 内容 |
|---|---|
| IID | 训练范围内未见实例 |
| 规模内插 | 训练规模点之间的组合 |
| 规模外推 | 超过训练上界的节点数、废物数或时期数 |
| 参数偏移 | 产生、库存、能力、成本和风险分布改变 |
| 空间偏移 | 坐标分布或现实地理实例改变 |
| 结构偏移 | 技术和共载兼容结构改变 |
| 偏好网格 | 稠密且包含训练未直接采样的偏好 |

## 14. 最低测试要求

### 14.1 图构建

- 节点数严格等于 $|I||S|+|J|$；
- 编码边数与完全有向图及自环设置一致；
- 边方向、距离、事故概率和节点对一一对齐；
- 节点顺序置换不改变对应输出；
- 跨期更新不改变任务/设施节点数和邻接结构；
- 同一产生者的不同废物任务共享坐标和产生者级容量特征；
- 同一 $(i,s)$ 跨期服务时复用同一节点，只更新动态库存和计划访问特征；
- 设施间边和自环可以参与编码，但永久不能被选为当前模型的运输动作。

### 14.2 库存与时期

- 当前期特征不泄漏不可用的未来决策；
- 提前服务不能收集未来产生量；
- 产废端和设施端库存逐期守恒；
- 不同 $|S|$ 只改变共享参数的任务节点数量，不改变单节点输入与嵌入维度；
- 已冻结时期不被局部算子和修复器修改。

### 14.3 期末约束

- 最后一期正库存任务不能被错误屏蔽；
- 明显无法在剩余能力内清零的动作被拒绝；
- `terminal_penalty_only` 只用于消融，不改变正式验收；
- 最终 $I^P_{i,s,H}=I^F_{j,s,H}=0$；
- 修复失败返回 incumbent，不返回伪可行解。

### 14.4 泛化和偏好

- 一个冻结检查点处理所有主测试规模和偏好；
- $(1,0)$、$(0,1)$ 及连续中间偏好均可运行；
- 不使用固定 producer/facility/vehicle/waste ID 输出槽位；
- 所有方法使用相同实例、归一化、检查器和墙钟预算。

## 15. 与当前代码接口的已知差异

在实现 GAT 前需要明确以下问题，不能在图构建器中静默改变数学模型：

1. 当前 `src/instance_generator.py` 给每个 `n::i::s` 独立生成坐标，而且 `ModelParams` 没有保存坐标。应改为先为每个产生者 $i$ 生成唯一坐标，其所有 $s$ 共享该坐标；同时保存坐标或完整编码边属性。
2. 当前 `ModelParams` 只保存实际允许运输弧的距离和事故概率。Lei 式完全编码图还需要同址任务边、设施—设施边和自环的明确定义：同址任务距离为零或同一地理距离；设施—设施使用真实道路距离；自环距离为零。它们可以参与信息交换，但由 `route_allowed=0` 永久禁止成为当前模型的运输动作。
3. 当前 MIP 需要补充严格的子回路消除/连通性验证，避免出现与任何设施脱离的产废点循环。正式 GAT 检查器不能把这种情况当作可行。
4. 路线起终点设施必须能处理路线所载全部废物；该业务规则应在统一检查器和动作掩码中直接实现，不依赖现有约束构造中的偶然索引行为。
5. 当前 GA 把大量收集集中到最后时期，不能作为 GAT 的周期语义依据；周期与库存状态以 MIP 库存守恒和 `require_terminal_clear` 定义为准。

这些属于后续实现前置项，本次只更新设计文档，不修改 MIP、GA 或求解结果。

## 16. 论文表述边界

在完成实验前可以表述：

> 本文以 Lei 等的 residual edge-GAT 为结构基准，使用产生者—废物取货任务与处置设施构成完全有向编码图，并通过动态周期库存特征、废物条件边属性、偏好条件解码和硬可行性机制扩展到多周期多目标危险废物运输问题。

只有在冻结单检查点通过规模和分布外测试后，才可以表述：

> 该模型在所测试的规模、规划期和偏好范围内表现出经验泛化能力。

不应表述为：

> GAT 天然保证任意规模泛化，奖励惩罚天然保证期末库存清零，或该方法保证得到 Pareto 最优解。

神经求解器仍是近似方法；小规模最优性由 MILP/$\varepsilon$-约束基线验证，大规模质量由 GA、滚动启发式、严格可行率和 Pareto 指标共同评价。
