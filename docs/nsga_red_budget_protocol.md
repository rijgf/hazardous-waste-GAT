# 红线参数按论文预算重跑 NSGA-II

用户要求采用范围探索图中的红线参数，按数值实验Markdown原预算重新求解NSGA-II、更新文稿并重绘PPO对比图。只更新Markdown，不修改Word，不重训或重跑PPO/MILP；当前请求不包含提交推送。

## 运行锁定

- N=20、pc=0.1、pm=1.0、非末周期随机初始服务概率=0.5。保留原编码、解码、单分量变异、修复、拥挤距离、锦标赛和父子代精英选择；原核心源码SHA256不变。
- 四个固定规模仍各用原000实例及绑定b。正式NSGA种子从v11原档案读取，不使用低预算探索种子取代正式种子。
- 四规模各3次至B1=40320，Test-4的相同3次接续至B2=120960，共12次演化、15个预算档案。B2不是新重启，时间为从同次起点累计到该预算，包含B1快照写盘。
- 种群初始化新增19个候选，完整子代批20个，所有重复和不可行尝试均计入预算。外部档案记录全部发现的合法非支配方案，不反馈选择。
- 4个工作进程，每进程数值库线程限制1；优先启动3个Test-4任务，另一工作进程依次处理较小规模。执行元数据记录实际PID、UTC起止与完成文件哈希。旧PPO为另一批次的计时，不声称公平速度比。
