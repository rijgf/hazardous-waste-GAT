## 共载附加风险：随机强度而非精确五倍标定

对每个允许共载的异类品类对，使用由原实例种子派生的独立固定随机种子抽取附加强度 κ∈Uniform(2,5)，设置 γ(s,s′)=κ×[h(s)+h(s′)]/2。不四舍五入，不把最大的品类对强制设为某个固定倍数；同类系数仍为0。

因此，仅比较同一路段、同事故参数、两类等正载量时，“普通运输风险＋共载附加风险”相对于两类各自普通运输风险之和，比例在3—6之间。这个关系不适用于任意不同载量、不表示全系统风险倍数，也不限制三类及以上共载时多个品类对的累加结果。

此为用户要求的合成压力情景，不是现实化学事故的经验标定。[EPA兼容性资料](https://www.epa.gov/hwpermitting/method-determining-compatibility-hazardous-wastes)支持品类组合应分别评估危险性，但不提供通用的3—6倍定量关系。现有兼容矩阵不变，不把本来禁止共载的组合改成仅受软风险惩罚。

## 处理能力：有效设施的系统合计口径

对每类废物先计算全系统平均单周期产生量。每周期所有具备该类处理技术的设施，其有效处理能力合计为该平均量的2倍；在有效设施间等额分配，不进行数值舍入。

技术禁止的单元保留正名义容量以兼容既有编码与预检，但有效容量始终由技术标记乘为0，不计入系统合计能力。分配份额在敏感性各水平间不改变。

敏感性仍为Test-4同一基础网络：处理能力或共载系数单独乘0.7、0.8、1、1.2、1.3，共9情景，不为追求曲线分离改动其他参数。

## 公共参考方案和b

新容量下旧的末期集中收运起点不保证可行。准备阶段采用固定、与成本风险无关的逐期服务构造：每周期用车辆—设施分配模型安排全部收运实体，限制车辆载量、技术匹配、该期设施处理能力及路线连接，再构造路线并调用原严格评价器验证。

该分配只服务于公共起点准备，不是正式MILP基准，不向正式MILP提供暖启动；准备时间、求解状态及方法单独记录。基准参考方案若在某敏感性情景仍可行则复用，否则按同一准备规则构造新参考方案。

派生记录中的 `reference_seed` 保留母实例原参考种子供来源追溯，不表示本轮运行了旧贪心构造；本轮实际参考构造方法及分配求解器固定种子0记录在 `reference_construction` 中。

所有新实例/情景在正式训练或求解前绑定一次正b_C、b_R；之后不随模型、偏好、重复、当前解改变。PPO输入、奖励及加权择优使用当前实例同一组b。跨情景比较原始C、R，不按不同b下的J作优劣排序。
