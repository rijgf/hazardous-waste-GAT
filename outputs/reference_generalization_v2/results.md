# 固定参考尺度与多实例训练：四规模泛化结果

结论：在本轮固定训练预算和独立测试集上，已出现“小模型在小规模更好、大模型在大规模更好”的宏平均结果。Test-1中新小模型比新大模型低0.458%，10个实例中有8个更好；Test-4中新大模型比新小模型低1.508%，10个实例的宏平均目标均更好。但并非所有修改后的结果都改善：新小模型在Test-4上比旧小模型差1.240%。

训练集：小、大规模各24个实例；测试集：四种规模各10个独立未见实例。训练参数与原配置一致（20轮×24个episode×24步，每轮24次更新），各实例参与20个episode。
每个实例锁定参考解和b_C、b_R。新模型的目标输入、奖励与搜索采用同一参考尺度；旧模型保持其原始编码。每个实例、偏好、模型运行3个相同求解种子。

新旧模型的训练数据、目标输入语义及训练随机种子不同，因此本轮比较不能单独识别归一化修改的因果贡献。旧模型和新模型在完全相同的新测试集上比较；不与历史50实例均值混算。每个训练规模只训练一个新检查点，表中标准差来自10个测试实例，不是多次独立训练的标准差，不能据此声称已经证明训练稳定性。

New-S/New-L分别为本轮的小/大规模模型；Old-S/Old-L分别为原有的小/大规模模型；GA为原配置遗传算法。规模以“产废节点/品类/设施/车辆/周期”表示：Test-1=3/2/2/3/2，Test-2=6/2/2/4/3，Test-3=10/3/3/5/3，Test-4=20/4/3/8/4。
